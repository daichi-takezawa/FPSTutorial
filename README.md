# FPSTutorial

ZennのUnreal Engine 5の教科書 [C++入門編,第三巻] 第9章 FPS制作チュートリアルのソースコードです。

## 含まれているもの
- Source (C++コード)
- Config (プロジェクト設定)
- FPSTutorial.uproject

アセット(Contentフォルダ)は含まれていないため、このリポジトリだけではプロジェクトを開けません。
アセットは9-2の手順でLyraStarterGameから移行してください。

## ページとタグの対応
| ページ | タグ |
|---|---|
| 9-1 プロジェクトの作成 | なし(C++コードの変更なし) |
| 9-2 アセットの移行 | なし(C++コードの変更なし) |
| 9-3 プレイヤーを作成しよう | 9-3 |
| 9-4 プレイヤーの移動と視点移動を実装しよう | 9-4 |

ページ上部のmainと書かれたボタン > Tagsタブからタグを選ぶと、そのページ時点のコードを見られます。
mainには最新のページまでのコードが入っています。

## 動作環境
- Unreal Engine 5.8
- Visual Studio 2022
