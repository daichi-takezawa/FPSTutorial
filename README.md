# FPSTutorial

Zenn「UE5 C++入門」第9章 FPS制作チュートリアルのソースコードです。

## 含まれているもの
- Source (C++コード)
- Config (プロジェクト設定)
- FPSTutorial.uproject

アセット(Contentフォルダ)は含まれていないため、このリポジトリだけではプロジェクトを開けません。
アセットは9-2の手順でLyraStarterGameから移行してください。

## ページとタグの対応
| ページ | タグ |
|---|---|
| 9-1 プロジェクトの作成 | 9-1 |
| 9-2 アセットの移行 | 9-2 |
| ... | ... |

ページ上部のmain > Tagsからタグを選ぶと、そのページ時点のコードを見られます。

## 動作環境
- Unreal Engine 5.8
- Visual Studio 2022
